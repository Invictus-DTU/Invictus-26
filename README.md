## ✨ Key Features & Highlights

This iteration of the Invictus platform was a massive leap forward, pushing the boundaries of web experiences with immersive 3D interactions and advanced performance strategies.

### 🧊 Immersive 3D Hero Experience
A major milestone for the team: the landing page introduces users with a custom, fully interactive 3D model. It smoothly responds to user interactions, creating an unforgettable first impression right at the top of the page.

### 🛕 Indian-Themed Premium UI
Transitioning seamlessly from the 3D hero section, the website reveals a meticulously crafted Indian-themed interface. It perfectly blends our cultural aesthetics with modern, high-end web design standards.

### 🗺️ Smart Dashboard & Interactive Campus Map
The user dashboard was built for true utility on the day of the fest. 
- **Interactive Navigation:** Features an interactive map that guides participants to exact event locations across the campus.
- **Participant Hub:** Allows users to easily view their team details, schedules, and event registrations in one place.

### ⚡ Architecture & Performance Strategy
We engineered the frontend to be incredibly fast and cost-efficient:
- **Next.js & SSR:** Leveraged Next.js for its robust routing and Server-Side Rendering (SSR) capabilities, ensuring fast initial loads and great SEO.
- **Aggressive PWA Caching:** Implemented a strong Progressive Web App (PWA) strategy. By storing UI data and components heavily on the client side, we drastically reduced network payload, loading times, and backend bandwidth.
- **Cloudflare CDN:** Used in tandem with our architecture to cache assets globally, further reducing database and server costs.

## 🛠️ Frontend Tech Stack
- **Framework:** Next.js (React)
- **Optimization:** Progressive Web App (PWA) & Server-Side Rendering (SSR)
